* **UC-101: Password Authenticate:** User supplies Email and Password. Engine checks k-anonymity breach list and verifies hash via Argon2id.

```mermaid
sequenceDiagram
    autonumber
    actor User as Unauthenticated Visitor
    participant BC as AuthRESTController <br/>(«boundary»)
    participant LC as LoginControl <br/>(«control»)
    participant HIBP as HaveIBeenPwnedAdapter <br/>(«boundary»)
    participant RC as RiskAssessmentControl <br/>(«control»)
    participant U as User / AuthenticationIdentity <br/>(«entity»)
    participant TD as TrustedDevice <br/>(«entity»)
    participant RF as RefreshTokenFamily / AuthSession <br/>(«entity»)
    participant AL as AuditLog <br/>(«entity»)

    User->>BC: POST /api/v1/auth/login <br/>(email, password, deviceFingerprint)
    
    rect rgb(240, 240, 240)
        note over BC, HIBP: 1. Password Verification & Breach Check
        BC->>LC: processPasswordLogin(email, password, clientContext)
        LC->>HIBP: checkBreachedPassword(passwordHashPrefix)
        HIBP-->>LC: breachStatus (isPwned: false)
        
        LC->>U: findAndVerifyCredentials(email, password)
        U-->>LC: isValidCredentials (true / false)
        
        alt Credentials Invalid
            LC->>AL: recordEvent("LOGIN_FAILED_INVALID_CREDENTIALS", email)
            LC-->>BC: HTTP 401 Unauthorized (RFC 7807 Error)
            BC-->>User: Return Invalid Credentials Error
        end
    end

    rect rgb(230, 245, 245)
        note over LC, TD: 2. Adaptive Risk Assessment
        LC->>RC: evaluateRisk(userID, ipAddress, deviceFingerprint)
        RC->>TD: findDevice(userID, deviceFingerprint)
        TD-->>RC: deviceRecord
        RC-->>LC: riskScore (High / Low)

        alt High Risk Detected
            LC-->>BC: HTTP 403 Forbidden (AUTH_MFA_STEP_UP_REQUIRED)
            BC-->>User: Step-Up MFA Challenge Required
        end
    end

    rect rgb(240, 255, 240)
        note over LC, AL: 3. Session Creation & Concurrent Cap Enforcement
        LC->>RF: enforceConcurrentSessionCap(userID, maxCap=10)
        opt Active Session Families > 10
            RF->>RF: revokeOldestSessionFamily()
        end

        LC->>RF: createSessionAndFamily(userID, clientContext)
        RF-->>LC: sessionInstance, refreshTokenPair

        LC->>TD: updateTrustMetrics(ipAddress, fingerprint)
        LC->>AL: recordEvent("LOGIN_SUCCESS", userID)
        
        LC-->>BC: issueTokens(accessToken, refreshToken)
        BC-->>User: HTTP 200 OK (Set Cookies / Return JWT Payload)
    end
    ```
